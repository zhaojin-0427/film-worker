# 首版镜头表

观察当前作业的 `镜头参考/*.jpg`。每行按源帧号展示一个候选镜头的首、中、末帧，必要时查看原尺寸源帧。暗切、闪光、遮挡和镜内转身都需根据实际画面判断。先写 UTF-8 的 `shot-plan.json`。编译器生成原生相机、场景、动作关键帧和连续的 `meta.jsonl`。下例为 24 帧示意，片长、物件和镜头均以本次原片为准。

```json
{
  "objects":{
    "person":{"kind":"actor","height":1.72,"palette_role":"lead"},
    "table":{"kind":"box","size":[1.5,0.8,0.75],"palette_role":"foreground"},
    "cup":{"kind":"cylinder","size":[0.09,0.09,0.12],"palette_role":"prop"}
  },
  "shots":[{
    "start":1,"end":24,"description":"人物面向桌子，伸出右手靠近杯子。",
    "camera":[{"f":1,"eye":[0,-4,1.5],"aim":[0,0,1],"lens":42}],
    "tracks":{
      "person":[{"f":1,"uv":[0.32,0.38],"anchor":0.9,"screen_h":0.82,"rot":[0,0,35]},
                {"f":18,"pose":{"upper_arm.R":[-60,0,0],"forearm.R":[-25,0,0]}}],
      "table":[{"f":1,"at":[0.7,0.1,0.375]}],
      "cup":[{"f":1,"at":[0.7,0.1,0.81]}]
    }
  }]
}
```

- 每个镜头从 1 起连续覆盖源帧，含结束帧。相机和各物体的第一组关键帧从本镜头首帧开始。新镜头独立设位和姿态。每个镜头只放出现在它的 tracks 里的物体。整个镜头保持的状态只写一个关键帧。
- 相机位置 eye、注视点 aim 都是 Blender 世界坐标，Z 向上，镜头 lens 单位毫米，默认水平画幅 36 mm。相机移动、摇摄、变焦时添加相机关键帧。roll 为画面滚转角度。物体若在世界中静止，仅设一次位置，随后相机可绕它移动。
- 世界位置用 at，或用 uv 指定画面位置。uv 为整张原帧左上角起的横纵比例，允许出画。depth 是相机前向距离（米），也可用 screen_h 指定物体完整竖直高度占画面高度的比例，近景允许大于 1。anchor 表示投影点相对物体原点向上的距离占模型高度的比例。人偶原点在脚底，anchor=0.92 可用面部找位置。几何体原点在中心。uv 仅在填写的帧反算成世界坐标。
- 物体 rot 和 pose 都用 XYZ 度数。人偶站立时正面朝 -Y，向画面右方转身可调 rot 的 Z，脊柱和头的扭转写 torso、head，左右以角色自身为准。可用 upper_arm.L/R、forearm.L/R、thigh.L/R、shin.L/R。pose 的角度相对自然垂臂站姿。左臂抬向身体左侧用 upper_arm.L 的负 Y，右臂用正 Y。向前伸臂用负 X。未写的关节延续上次的姿态。preset 支持 stand、sit、step.L、step.R，切换会重置全身姿态，坐下时把髋部随椅面下移。关键帧在镜头内线性过渡，动作停顿要在起止两端写同一状态。
- 分开判断骨盆、胸口和头部。用人物整体位置与旋转表现骨盆朝向和重心，胸口、头和四肢分别设姿态。人体整体尺寸和各部位比例在各镜头保持一致，画面上的大小和裁切通过位置、机位与镜头参数对齐。
- actor 取自本批基础模型 L3，保留原始网格和方向条，禁止添加外观部件或改材质模拟。box、sphere、cylinder、cone 的 size 为 XYZ 全尺寸（米）。group 可用 parts 组合命名部件，子件以局部 at、rot、size 摆放。为需单独运动的子件另设对象，定义 parent 指向同镜头的其他道具。手持道具可在镜头表中通过 person:forearm.R 或 person:forearm.L 挂接到对应前臂，局部位置用 at。画面有上下黑边时，每镜 bars 可填 [顶部比例,底部比例]。
- 人物的 `palette_role` 必填，使用 `lead`、`second`、`third`、`fourth` 或 `extra`。非人物物体用 `foreground`、`background` 或 `prop`。组合体的子部件默认继承类别，组合体和独立道具未填写时默认为 `prop`。色值由程序决定，同一角色跨镜沿用同一对象 ID。
- 复杂场景几何和额外接触动作可用本轮的 `scene_details.py` 补充。脚本在每次编译时于保存之前执行，可直接使用 `bpy`、`scene`，从 `cast[镜头起始帧][对象ID]` 取得根物体，角色关节在 `joints[镜头起始帧][对象ID]`。补建网格使用 `apply_palette(物体, 类别)`，并挂在本镜根物体或链接到 `shot_collections[镜头起始帧]`，编译器会设置它的出镜范围。
- 编译命令见本轮任务，可在末尾追加 `--preview 1 12 24` 低清试渲指定源帧到 draft-preview。按原片回看主体位置、角度、遮挡和动作，调整数据后再次编译。全片送审由工作台执行。
