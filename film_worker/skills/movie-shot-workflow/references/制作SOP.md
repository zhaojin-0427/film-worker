# 电影复刻制作 SOP

## 制作资料

- 所有制作和预览统一使用 Cycles。通过后台启动器编译、检查和渲染。Eevee 和 Workbench 会初始化图形界面，工作台在送审前拦下这类引擎切换。

- 制作输入只使用当前作业的原片、编号源帧、候选镜头参考，本轮返修单和指定的基版，以及工作台随提示注入的规则、内置工具和指定人体白模。历史试制、个人下载目录、工作区其他作业、网络素材和用户自行安装的规则均不属于制作输入。中间文件与写入只放本轮目录。
- 人物一律使用甲方指定的基础模型，从配置的 `.blend` 复制 L3。保留原模型的比例、表面结构和材质特性，保留面部与胸口的原有方向标记。白模主体颜色由工作台固定映射赋值。人物只调整位置、朝向、关节姿态和动作关键帧。禁止重塑、换模或拉伸，禁止添加衣服、帽子、兜帽、头发、五官、额外手掌或手指，也禁止通过贴图或材质模拟这些外观。画幅和露出部位通过相机、构图和动作对齐。
- 角色跨镜头沿用同一对象 ID 和角色类别，主角、第二、第三、第四角色分别为红、蓝、绿、黄，其他人物用固定中性灰。前景用棕、背景用灰，普通道具用中性灰。编译器依据 `palette_role` 上色，原片衣服颜色只用于识别人。补建网格调用 `apply_palette(物体, 类别)` 上色并记录类别，返修沿用已有角色类别和人体方向标记。只做局部返修时，沿用旧工程已经通过的其余画面。
- 场景、遮挡物、人物和道具使用可编辑的原生三维几何及材质。原片和对比图仅用于观察，禁止贴原片、视频平面、图片描摹进工程，以及链接或打包外部素材。按原片需要增补几何，避免凭空增加表演、道具、布景或运镜。

## 首制

1. 从头到尾看原片，弄清人物、动作和前后镜头的逻辑，再读带帧号的候选镜头图。对疑似误切、暗场、闪光或动作突变，查看切点前后的连续源帧，用画面证据确认后拆镜或合镜。记录改过的切点、相邻帧号和依据。暗部观察图仅帮助辨认内容。
2. 完成全片镜头表。逐镜对齐画幅、裁切、透视、机位和运动，检查主体投影大小、位置、朝向、出入画、遮挡和露出的身体部位。补齐影响动作或空间判断的前后景、地面、支撑和道具。
3. 分开判断骨盆、胸口、头部和四肢的姿态。复查腿弯、足距、脚底接触、左右换重和支撑阶段，防止无依据的浮空。被遮挡或在画外的动作按出画前、回画后的连续帧做最小推断，保持肢体稳定。保留画面中可见的轻微动作、停顿和原有动作节奏。逐段检查取放、松手、手与道具接触、穿插、抽动、跳变、闪烁和动作提前停住。
4. 试渲各镜首、中、末、动作转折和整体片尾。检查切镜的前一帧和后一帧，逐帧复核片尾最后一秒的黑帧、漏帧和动作截断。原片本身的黑场、遮挡和闪光按可见证据还原。
5. 首版送审前编码一条涵盖完整时间线的上下自检对比片，和原片按镜头从头到尾核对。工具无法播放时，从编码后的对比片解码并连续检查各镜头和运动段。发现偏差就修改工程、重渲、重新编码并复查。批量制作时每条独立检查。制作经验先写本单记录，能改善其他片子时再由维护者纳入通用规则。
6. 给工作台提交可渲染、可编辑的 `scene.blend`、按帧连续覆盖全片的 `meta.jsonl`、当前工程对应的自检对比 MP4 和 `制作记录.md`。首制由工作台编译 `shot-plan.json` 生成工程和镜头信息。记录改过的切点、核对范围、自检发现及仍需人工判断的帧段。

## 返修与交付

- 按本轮摘要和逐帧原始意见核对指定基版。区间反馈先看首、中、末及转折帧，圈选按标有数字的预览图对应意见。集中修完整段受影响的动作、相机或物体，再看修改区间相邻帧，保留已对齐内容。返修后完整复看重新编码的对比片，记录实际核对的帧段和仍需复核的偏差。
- 独立审核先核对 L3 基础外观与固定配色，再查镜头、姿态、接触、遮挡和节奏。每条问题写清帧段、原片表现、复刻偏差和可执行的修改项。人物偏差用位置、朝向、关节姿态、动作关键帧修正，构图和透视通过镜头调整。出现违规部件或材质改造时，指出帧段并要求恢复 L3。
- 原片、工程和审核用同一帧号，从第 1 帧到原片末帧。保留真实显示时码、帧时长与原片画幅，禁止裁掉源帧或固定帧率重采样。音轨和编码由工作台负责。
- 工作台按 1080P 审核规格全量渲染，上方原片，下方白模。像素或时码变动、有遗留意见、从未审核的帧进入人工复核。全部通过才出成片，输出按作业选择 1080P 或 4K，同步归档原片、白模、对比、工程和镜头信息。
- 制作记录注明「Codex 内部试制」。当前正式验收材料的制作方式要求为人工制作。各正式批次仍需确认规格：其中一批要求至少 4K、15 秒，另一批要求至少 1080P、5–60 秒，两批均列至少 24 fps 和视频码率至少 18 Mbps。
